# KIM2

Digital riskbedömning för manuell hantering – skjuta/dra, utformad i samma visuella serie som KIM3.

Metoden bygger på Arbetsmiljöverkets KIM 2-material (version 2012) och innehåller tidspoäng, massa/hjälpmedel, positionering/rörelsehastighet, arbetsställning, arbetsförhållanden samt automatisk riskutvärdering.
